# 快速开始

本文档面向第一次使用智能网关的用户。5 分钟内在本地跑起来。

## 1. 环境要求

- Python 3.10+（推荐 3.11+）
- Node.js 18+（仅构建前端时需要）
- Windows / macOS / Linux

## 2. 安装后端依赖

```bash
cd ai-gateway-pro
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

## 3. 构建前端

```bash
cd web-vue
npm install
npm run build
```

构建产物输出到 `web/` 目录，由后端 FastAPI 静态托管（无需单独部署前端服务）。

## 4. 启动

### 方式一：桌面客户端（推荐）

```bash
python desktop/desktop.py
```

桌面壳自动完成：初始化 WebView2 → 启动内置后端 → 等待 `/api/health` 就绪 → 加载界面。

### 方式二：纯 Web 模式

```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8765
```

打开浏览器访问 `http://127.0.0.1:8765`。

### 方式三：打包为 exe（Windows）

```bash
pip install pyinstaller
pyinstaller ai_gateway_pro.spec
```

输出在 `dist/智能网关.exe`，双击运行。单文件 exe 的数据持久化目录在工作目录旁的 `gateway_data/`。

## 5. 首次使用流程

1. 注册账号（或使用默认管理员）
2. 打开「渠道管理」→ 添加上游渠道（支持手动填写或模板一键添加）
   - NVIDIA：`https://integrate.api.nvidia.com/v1`
   - 魔搭：`https://api-inference.modelscope.cn/v1`
3. 渠道添加后自动拉取模型列表，并自动生成内置路由组
4. 打开「API 密钥」复制你的 Key
5. 用任意 OpenAI 客户端调用：

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8765/v1",
    api_key="你的API密钥",   # 管理面板「API 密钥」页复制
)

# 用路由组名代替具体模型名
resp = client.chat.completions.create(
    model="high_quality",          # quick / high_quality / vision / 自定义组名 / 具体模型名 / 别名
    messages=[{"role": "user", "content": "帮我写一首诗"}],
)
print(resp.choices[0].message.content)
```

## 6. curl 示例

```bash
# 非流式
curl http://127.0.0.1:8765/v1/chat/completions \
  -H "Authorization: Bearer 你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"quick","messages":[{"role":"user","content":"你好"}]}'

# 流式（SSE）
curl http://127.0.0.1:8765/v1/chat/completions \
  -H "Authorization: Bearer 你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"quick","stream":true,"messages":[{"role":"user","content":"你好"}]}'

# 模型列表（OpenAI 兼容）
curl http://127.0.0.1:8765/v1/models \
  -H "Authorization: Bearer 你的API密钥"
```

## 7. 配置项（环境变量）

所有配置项前缀 `GW_`，可用环境变量或 `backend/config.py` 默认值覆盖。

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `GW_HOST` | `0.0.0.0` | 监听地址 |
| `GW_PORT` | `8765` | 监听端口 |
| `GW_DATABASE_URL` | SQLite `backend/data/gateway.db` | 数据库连接串（MySQL 可用） |
| `GW_PREFIX` | - | API 前缀 |
| `GW_DEBUG` | `false` | 调试模式（详细日志） |
| `GW_PROXY_TIMEOUT_SECONDS` | `20` | 上游请求超时（秒） |

桌面版通过 `GW_DB_PATH` 指定 exe 旁的持久化数据目录（打包时自动设置）。

## 8. 常见问题

### 桌面版窗口白屏

见 [README.md](../README.md#常见问题桌面版窗口白屏--无界面) 的完整排障指南。要点：

1. 确保目标机器安装 **Microsoft Edge WebView2 Runtime**
2. 确认后端已在监听：`netstat -ano | findstr :8765`
3. 旧 exe 建议用当前源码重新打包

### 端口被占用

```bash
netstat -ano | findstr :8765   # 找到 PID
taskkill /PID <PID> /F          # 结束进程
```

### 数据存在哪里

默认 SQLite 数据库在 `backend/data/gateway.db`。备份该文件即可备份全部数据（渠道、用户、用量、链路日志）。
