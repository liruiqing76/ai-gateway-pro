# 智能网关（AI Gateway Pro）— 项目概览

> 聚合多渠道 AI 模型，统一 OpenAI 兼容接口，提供路由、熔断、故障转移、编排、额度管理与全链路追踪的开源网关。

## 1. 这是什么

智能网关是一个**个人/小团队级 AI 流量聚合网关**，解决以下痛点：

- **多渠道分散**：NVIDIA、魔搭、SenseNova 等平台各有免费额度，逐个调用和管理繁琐
- **稳定性差**：单个上游模型超时或报错会中断整个请求
- **模型名混乱**：不同平台同一能力的模型命名不统一（`z-ai/glm-5.2` vs `glm-5.2`）
- **额度不可控**：免费渠道每日/每月有额度上限，超限前无人提醒、超限后请求失败

网关将这些渠道统一收编后，对外暴露**一个** OpenAI 兼容端点（`/v1`），客户端只填一个简单的模型名（或路由组名），剩下的路由决策、故障转移、额度控制全部由网关完成。

## 3. 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Python 3.10+ / FastAPI / SQLAlchemy 2.0 / httpx |
| 数据库 | SQLite（本地默认）/ MySQL 8.0（可选） |
| 前端 | Vue 3 + Element Plus（Vite 构建） |
| 桌面 | pywebview + PyInstaller 打包 |
| 安全 | bcrypt 密码哈希、PyJWT、AES-256-GCM 密钥加密 |
| 测试 | pytest + pytest-asyncio（124+ 用例，含性能基准） |

## 4. 快速上手

```bash
# 1. 安装后端依赖
pip install -r requirements.txt

# 2. 构建前端
cd web-vue && npm install && npm run build

# 3. 启动（开发模式）
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8765

# 4. 桌面模式
python desktop/desktop.py
```

详细步骤见 [快速开始](01-快速开始.md)。

## 5. 项目结构

```
ai-gateway-pro/
├── backend/                 # FastAPI 后端
│   ├── main.py              # 应用入口，路由注册
│   ├── config.py            # 配置（pydantic-settings, GW_* 环境变量）
│   ├── api/                 # API 路由层
│   │   ├── proxy.py         # /v1/chat/completions, /v1/models（核心代理）
│   │   ├── providers.py     # /api/providers 渠道 CRUD + 模板
│   │   ├── routers.py       # /api/routers 路由组 CRUD
│   │   ├── router_check.py  # 路由组可用性检测
│   │   ├── usage.py         # /api/usage 用量统计
│   │   ├── aliases.py       # /api/aliases 模型别名
│   │   └── traces.py        # /api/traces 请求链路日志
│   ├── core/                # 核心引擎
│   │   ├── proxy.py         # 模型选择 + 转发（流式/非流式）
│   │   ├── circuit.py       # 熔断器
│   │   ├── scheduler.py     # 质量评分调度器
│   │   ├── router_group.py  # 路由组分类
│   │   ├── orchestrate.py   # 多模型编排（relay/review, 支持流式）
│   │   └── trace.py         # 请求链路追踪上下文
│   ├── auth/                # 鉴权（JWT / API Key / 加密）
│   ├── billing/             # 计费模块
│   ├── models/              # SQLAlchemy ORM 模型
│   └── checkin/             # 自动签到
├── web-vue/                 # Vue 3 前端源码
├── web/                     # 前端构建产物（后端静态托管）
├── desktop/                 # pywebview 桌面壳
├── tests/                   # 测试套件（124+ 用例）
└── docs/                    # 本文档
```
